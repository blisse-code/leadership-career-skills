# How the skills work together

| Stage | Skill | Hands off |
|---|---|---|
| 1. Evidence | `leadership-resume-architect` builds the Leadership Evidence Bank and Target Map | Evidence log, interview story seeds |
| 2. Proof | `ux-leadership-case-study` turns the 2-3 strongest items into decision-led case studies | 2-3 resume bullets and one cover-letter sentence per case |
| 3. Letter | `bespoke-cover-letter` harvests proof from 1 and 2 and checks consistency | Signature story candidate |
| 4. Portfolio | `principal-head-experience-ai-portfolio-architect` arranges cases, dossier, and visual system | Talk tracks |
| 5. Delivery | `leadership-storytelling` builds the story bank, panel talk tracks, walking deck, and 30-60-90 | |

`tailored-resume-generator` is the non-leadership path for stage 1.

Shared rules across all six: no invented metrics (placeholders instead), honest attribution ("I" vs "the team"), no em dashes, no hype vocabulary, and plain language that a non-designer executive can follow.
