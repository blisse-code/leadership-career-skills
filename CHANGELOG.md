# Changelog

## 1.0.0 (2026-09-28)
### Added
- `leadership-resume-architect`: leadership resumes and CVs, level ladder, eight leadership dimensions, ATS and country conventions, `render_resume_docx.py`, `ats_check.py`.
- `ux-leadership-case-study`: decision maps, responsibility maps, nine case types, 12-point rubric, panel deck guide.
- `leadership-storytelling`: story banks, frameworks (Ganz, Simmons, Denning, Duarte, Minto, Heath), exec pitches, walking deck, 30-60-90 plans.
- ChatGPT editions of all six skills; Custom GPT fallbacks for the three new skills.
- Claude Code plugin marketplace, installer script, validator, build script, CI.
- Evals: 9 prompts, fictional inputs, grader, benchmark results.

### Changed
- `tailored-resume-generator`: no-fabrication rule; fabricated-metric example removed; two-page guidance for senior candidates; country conventions; routes leadership roles to the resume architect.
- `bespoke-cover-letter`: leadership-level calibration; consistency check with resume and case studies; relocation only when confirmed; no speculation about the employer's internals.
- `principal-head-experience-ai-portfolio-architect`: leadership portfolio signals; leadership signature and level in Phase 1; mandate, leverage, and decision-map scoring in Phase 2.
